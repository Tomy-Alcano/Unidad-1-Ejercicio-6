# Unidad-1-Ejercicio-6
Programacion 3 Unidad 1, Ejercicio 6
Ejercicio 6 — Ventana de inicio de sesión
Uno de los formularios más comunes en cualquier aplicación de escritorio es la pantalla de login. En este ejercicio vas a construirla desde cero, combinando los componentes básicos aprendidos en la unidad.

Creá una ventana que simule una pantalla de inicio de sesión con los siguientes elementos:

Una etiqueta con el texto "Iniciar Sesión" que funcione como título del formulario
Una etiqueta y un campo de texto para ingresar el Usuario
Una etiqueta y un JPasswordField para ingresar la Contraseña (investigá este componente: es similar a JTextField pero oculta los caracteres ingresados)
Un JCheckBox con el texto "Mostrar contraseña", que inicie desmarcado
Un botón con el texto "Iniciar sesión"
Un botón con el texto "Cancelar"
La ventana debe tener un tamaño apropiado, aparecer centrada en la pantalla y cerrarse correctamente al presionar el botón de cierre.

💡 Tip: JPasswordField forma parte del paquete javax.swing al igual que JTextField. Investigá cómo se diferencia en su uso y qué método se utiliza para obtener la contraseña ingresada.
